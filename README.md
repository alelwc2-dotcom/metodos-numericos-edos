# Resolución Numérica de EDOs en Java (Euler y RK4)

Implementación modular de los métodos numéricos de **Euler** y **Runge-Kutta de 4to Orden (RK4)** para resolver Ecuaciones Diferenciales Ordinarias con condiciones iniciales, desarrollado para la asignatura **SCC-1017 Métodos Numéricos** (ITSX).

## Requisitos
* Java Development Kit (JDK) 8 o superior.
* Git instalado en el sistema.

## Clonación del Repositorio
Abre una terminal y ejecuta:
git clone https://github.com/alelwc2-dotcom/metodos-numericos-edos.git
cd metodos-numericos-edos
